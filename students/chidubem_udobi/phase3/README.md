# Phase III — Residential AI Mapper

Interactive Streamlit application for detecting candidate buildings in Ottawa/Kanata, Ontario, using aerial imagery and a pretrained YOLO model.

## Features
- Interactive aerial map
- Geographic rectangle selection
- Adjustable detection confidence
- AI building detection
- Geographic detection overlays
- CSV results export

## Running the application
Use Launch_Phase_III_in_Colab.ipynb in Google Colab and follow its instructions.

## Limitations
The model detects candidate buildings, not verified residential homes. WUI classification and local accuracy validation remain future work.
