# Canada Real Estate Map

This project explores the use of remote sensing and AI for building detection and real estate mapping across Canada.

### Progress 2 – November 12, 2026

**Work completed so far:**

Since the first meeting, I have started building my Canada Real Estate Map project using Python in Google Colab. I created a basic interactive map using Folium and added location markers representing properties in different Canadian cities.

I also created sample property data to test how the locations would appear on the map. This helped me get started with the map layout and understand how to display location information across Canada.

**Current user interface (UI):**

At the moment, the project has a basic interactive map prototype in Google Colab. It displays location markers on a map of Canada. It is not yet a complete website or dashboard.

**Interactive features:**

- **Map navigation:** Users can zoom in, zoom out, and move around the map.
- **Location markers:** Users can click on markers to view the sample property information associated with each location.

**Current limitations:**

The property information currently uses sample data created for testing purposes. The project is not connected to a real estate listing database yet. I have also not started the satellite imagery annotation or AI building-detection stages.

**What I plan to work on next:**

- Find suitable satellite or aerial imagery for selected locations in Canada.
- Prepare image samples and annotate buildings using LabelMe.
- Start developing an AI model to detect buildings in the images.
- Test the building-detection results and improve the model.
- Add the building information to the interactive map.
- Gradually expand the project to cover all 10 provinces and 3 territories.
- Improve the map and develop a more complete user interface.
